# SecureNet VPN/Proxy Website

A **self-contained, all-in-one VPN/Proxy website** with complete documentation, guides, and resources—all on a single platform with no external redirects.

## Features

✅ **Self-Contained** - All content hosted on one website  
✅ **Responsive Design** - Works on desktop, tablet, and mobile  
✅ **Comprehensive Documentation** - Installation, configuration, troubleshooting  
✅ **Security Focused** - Privacy and encryption details included  
✅ **No External Dependencies** - Everything is local  
✅ **Developer Friendly** - API documentation for developers  
✅ **MIT Licensed** - Open source and customizable

## Getting Started

1. **Visit the Website** - Open `index.html` in your browser
2. **Read the Setup Guide** - Follow the quick 4-step setup
3. **Download Configuration** - Get your client config from `docs/client-config.html`
4. **Install Client** - Follow platform-specific instructions
5. **Connect** - Enjoy secure browsing!
